# 07. 자동바이알계산기 — "설정" 화면(`pages/settings.jsx`) 구현 계획서

## 1. 목적
- 체이스의 요청에 따라 앱의 전반적인 환경과 옵션을 설정할 수 있는 **"설정" 화면**을 구현합니다.
- 특히 "기록" 화면의 드롭다운 선택창에서 쓰일 **"부서 입력/관리"** 기능(신규 부서 추가, 등록된 부서 목록 열람 및 삭제)을 중심으로 구성합니다.
- 추후 추가될 추가 설정 항목들(알림, 카메라 감도, 바이알 규격 기준값 등)을 유연하게 수용할 수 있는 깔끔한 카드 구조를 갖춥니다.

## 2. 화면 구성 요소
1. **화면 상태 스위처 (`.jt-switcher`)**:
   - `정상 데이터(5개 부서)` · `로딩중(스켈레톤)` · `빈 상태(등록 부서 0건)` 상태를 한 번에 테스트할 수 있는 임시 전환 버튼.
2. **"부서 관리 설정" 카드 (`.jt-card`)**:
   - **부서 신규 입력칸**: 새 부서명을 입력하고 [부서 추가]를 누를 수 있는 입력 필드(`.jt-input`)와 주버튼(`.jt-btn`).
   - **등록된 부서 목록 (가짜 데이터 5줄)**:
     - 1. 생산1팀 (기본부서 배지)
     - 2. 생산2팀
     - 3. 포장1팀
     - 4. 포장2팀
     - 5. 품질관리팀
     - 각 항목마다 담당 아이콘, 기본 부서 지정 여부, 삭제 버튼(`.jt-icon-btn`) 제공.
3. **추후 추가 예정 안내 카드 (`.jt-card`)**:
   - 카메라 및 AI 분석 감도 설정, 바이알 규격 관리 등이 들어올 예정 영역을 깔끔한 도움말 카드로 준비.
4. **빈 상태 (`.jt-empty`)**:
   - 등록된 부서가 하나도 없을 때의 안내 문구 및 빠른 추가 버튼.
5. **로딩 상태 (`.jt-skeleton`)**:
   - 설정을 서버나 로컬 저장소에서 불러올 때의 스켈레톤 UI.

## 3. 사용하는 `.jt-*` 컴포넌트 목록
- 레이아웃·카드: `.jt-card`, `.jt-row`, `.jt-stack-2`, `.jt-stack-3`, `.jt-stack-4`, `.jt-divider`
- 버튼·스위처: `.jt-btn`, `.jt-btn-sm`, `.jt-icon-btn`, `.jt-switcher`, `.jt-switcher-item`
- 입력·폼: `.jt-input`, `.jt-form-item`, `.jt-label`
- 리스트·태그·배지: `.jt-tag`, `.jt-badge`, `.jt-badge-pass`
- 상태·빈화면·설명: `.jt-empty`, `.jt-empty-title`, `.jt-empty-desc`, `.jt-skeleton`
- 텍스트·아이콘: `.jt-help`, `.jt-ico`, `.jt-ico-sm`, `.jt-ico-lg`
