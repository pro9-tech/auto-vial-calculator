# 06. 자동바이알계산기 — "기록" 화면 '차수' 추가 및 '담당부서' 선택 기능 구현 계획서

## 1. 목적
- 체이스의 요청에 따라 "기록" 화면의 표에 '제품명'과 '담당부서' 사이 **'차수'** 입력 필드를 신설합니다.
- '담당부서'를 정적 텍스트/태그에서 **선택 가능한 드롭다운 선택창(`.jt-select.jt-select-sm`)**으로 개선하여, 추후 [설정] 화면에서 등록될 부서 목록과 자연스럽게 연동될 수 있도록 기반을 마련합니다.

## 2. 세부 수정 사항
1. **'차수' 입력 열 신설**:
   - 위치: '제품명' 열과 '담당부서' 열 사이
   - 헤더: `<th>차수</th>`
   - 본문: 제품명과 동일하게 자유롭게 입력/수정할 수 있는 콤팩트한 인라인 입력칸(`.jt-input.jt-input-sm`) 배치 (예: `1차`, `2차`, `재검수` 등).
2. **'담당부서' 선택 기능 구현**:
   - 담당부서 셀을 클릭하여 선택할 수 있도록 `.jt-select.jt-select-sm` 컴포넌트로 변경.
   - 옵션 예시: `생산1팀`, `생산2팀`, `포장1팀`, `포장2팀`, `품질관리팀` (추후 [설정] 화면에서 관리 예정).
3. **가짜 데이터 5줄 갱신 및 상태 관리**:
   - 각 데이터 객체에 `round`(차수) 속성 추가 (예: `1차`, `2차`, `3차` 등).
   - `round`와 `team`을 사용자가 변경할 때 즉각 반영되도록 React State 핸들러 연결.
4. **한 줄 정렬 및 디자인 시스템 규칙 준수**:
   - `whiteSpace: 'nowrap'`, 글자 크기 `var(--fs-sm)`, 토큰 기반 간격 유지.

## 3. 사용하는 `.jt-*` 컴포넌트 목록
- 레이아웃·카드: `.jt-card`, `.jt-row`, `.jt-stack-2`, `.jt-stack-3`, `.jt-stack-4`

- 상태·빈화면·설명: `.jt-empty`, `.jt-empty-title`, `.jt-empty-desc`, `.jt-skeleton`, `.jt-desc`
