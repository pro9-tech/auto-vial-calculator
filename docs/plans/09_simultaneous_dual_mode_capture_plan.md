# 09. 자동바이알계산기 — "촬영" 화면 동시 복합 계산 및 듀얼 업로드 UI 구현 계획서

## 1. 목적
- 체이스의 요구사항을 완벽하게 반영하여, 모드를 선택해서 하나만 계산하는 것이 아니라 **"바이알 캡 계산(상단 촬영)"과 "카트 박스 계산(측면 촬영)"이 한 화면에서 동시에 나란히/함께 작동**하도록 개편합니다.
- 복합 계산 원리:
  - **카트 박스 총 바이알** = (인식된 박스 개수) $\times$ (박스당 바이알 수량 입력값)
  - **낱개 바이알 트레이 캡** = 상단 촬영으로 직접 파악된 바이알 캡 개수
  - **최종 총 바이알 합산** = (박스 내 바이알 수량) + (트레이 낱개 바이알 수량)
- 두 모드의 사진 추가 영역을 한 화면에 동시에 배치하여 각각 최대 10장까지 사진을 올릴 수 있도록 지원합니다.

## 2. 화면 구성 요소
1. **듀얼 업로드 영역 (나란히 또는 2단 카드 동시 배치)**:
   - **영역 A: [바이알 캡 상단 촬영 (낱개 바이알)]**
     - 트레이 위에서 찍은 캡 사진 추가 버튼 (`최대 10장`)
     - 사진 목록 썸네일 그리드
   - **영역 B: [카트 박스 측면 촬영 (박스 적재)]**
     - 카트 옆에서 찍은 박스 적재 사진 추가 버튼 (`최대 10장`)
     - **박스당 바이알 수량 입력칸** (`.jt-input`, 예: `100개/박스` 기본값 설정 및 자유 입력)
     - 사진 목록 썸네일 그리드
2. **복합 계산 통합 검수 버튼 (`.jt-btn.jt-btn-lg`)**:
   - `두 모드 일괄 복합 검수 시작`
3. **복합 계산 결과 카드 및 가짜 데이터 5줄 표**:
   - 최종 총 바이알 수량 요약 (`.jt-stat`):
     - `총 바이알 = 박스 환산 수량 + 낱개 캡 수량`
   - 분석 상세 내역 표 5줄 (`.jt-table-wrap` > `.jt-table`):
     - 구분 (카트 박스 / 트레이 캡), 파일명, 인식 수량, 계산 공식 및 환산 바이알 수
