# 19. HSV 배경 분리, 원근 왜곡 보정, 중앙 블롭 및 적재 박스/스테이플러 정밀 검출 고도화 계획서

## 1. 개요 및 목적
- **목적**: 실제 현장 사진(초록색 플라스틱 트레이 위 165개 캡 바이알, 카트 위 16박스 프라단 박스)에 맞추어 99% 정확도를 달성하기 위해, HSV 색상 마스킹, 캡 중앙 어두운 원형 점(블롭) 정밀 검출, 자동 원근 보정(Perspective Warp), 프라단 박스 1단 표준 높이 비율 및 은색 스테이플러 심 특징 분석 파이프라인을 구축합니다.
- **API 키 사용 배제**: 100% 브라우저 내장 OpenCV.js WASM 엔진 및 내장 캔버스 비전 연산으로 완전 로컬 구동.
- **화면 형태 및 원칙 준수**: 기존 UI 레이아웃, 인앱 모달, JT UX writing 원칙 및 JT 디자인 시스템 v5.0 엄수.

## 2. 세부 알고리즘 설계

### 2.1 캡 뚜껑 모드 정밀화
1. **HSV 색상 필터 기반 초록색 트레이 배경 제거**:
   - RGB -> HSV 변환 후, 초록색 트레이 영역(Hue: 65°~165°, Saturation: 25%~100%, Value: 20%~95%)을 식별하여 마스킹.
   - 트레이 배경을 제외한 전경 바이알 군집 영역(ROI)만 정밀 추출.
2. **트레이 외곽 코너 검출 및 자동 원근 보정 (Perspective Warp)**:
   - 비스듬한 촬영으로 인한 상하 원근 왜곡(상단 바이알은 작고 하단 바이알은 커지는 현상)을 보정.
   - 초록색 트레이의 네 모서리 윤곽선을 찾아 정면 직사각형 투시 변환을 적용하여 모든 바이알의 지름을 균일화.
3. **캡 정중앙 어두운 원형 점(코어 블롭) + 외곽선 이중 검출**:
   - 각 바이알 캡 정중앙의 어두운 원형 고무 구멍(Dark Core Blob)을 중심 앵커로 정밀 검출 (이미지 2의 1, 2, 3, 6번 마커처럼 정확한 중심 포착).
   - 중앙 점이 약하거나 없는 캡의 경우 원형 외곽선 윤곽선(Hough/Contour)을 보조 검출하여 결합.
   - 1바이알 1마커 원칙 엄격 적용 (반경 0.82 이내 동심원/중복 완전 억제).

### 2.2 박스 모드 정밀화
1. **HSV 초록색 박스 영역 추출 및 바닥 반사광 배제**:
   - 프라단 박스의 초록색 고유 HSV 대역만 추출하여 회색 바닥 및 바닥 반사광을 완벽히 분리.
2. **좌우 열(2줄) 분리**:
   - 전경 박스 영역의 세로 틈새를 찾아 좌측 열(Col 1)과 우측 열(Col 2)을 독립 분리.
3. **세로 명암 프로파일(수평 그림자 골짜기) + 박스 1단 표준 높이 비율 보정**:
   - Sobel Y 및 중앙 수평 띠 세로 프로파일을 통해 층간 그림자 골짜기(Valley) 탐색.
   - 프라단 박스는 모든 단의 높이가 일정하므로, 상단부 명확한 박스들의 **1단 표준 높이(Unit Height)**를 추정.
   - 열 전체 세로 높이를 1단 표준 높이로 나누어 반올림하는 높이 비율 보정 로직을 병행 적용하여, 맨 아래 카트 프레임에 가려진 박스까지 16박스(8단×2열)를 완벽하게 카운트.
4. **측면 은색 스테이플러 심(Stapler Pin) 보조 지표 검출**:
   - 각 박스 앞면 오른쪽 모서리 부근의 은색/고휘도 스테이플러 심 피크를 검출하여 층간 분할을 교차 검증.

### 2.3 카메라 촬영 시 가이드 프레임 UI 제공
- 촬영 화면에서 안내되는 가이드 오버레이를 통해 작업자가 트레이나 카트 정면/수직 구도를 직관적으로 맞출 수 있도록 점선 가이드 프레임 지원.

- `npm run build` 및 JT 디자인 시스템 검증.
