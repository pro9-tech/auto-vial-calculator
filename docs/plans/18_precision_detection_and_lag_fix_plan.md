# 18. 외곽 윤곽선 정밀 인식 및 슬라이더 렉 제거 계획서

## 1. 문제 원인 진단
1. **캡 뚜껑 모드 (과검출 및 오탐: 227개 검출)**
   - **겹침 제거 느슨함**: `dist < Math.min(c.r, k.r) * 1.48`로 인해 한 바이알 캡 위에 Hough 원과 Core-Ring 원이 중복(반겹침)으로 2개씩 찍힘.
   - **배경 오탐**: 덧신(발바닥), 트레이 모서리 등 원형 외곽 윤곽선이 없는 영역까지 밝기 대비만으로 검출됨.
2. **박스 모드 (가로 사진 적재 박스 윤곽선 부정확)**
   - 가로 사진(`h ≈ 675px`)과 세로 사진(`h ≈ 2191px`)의 높이 차이를 고려하지 않고 고정 간격(`48px`)을 써서 얇은 층간 구분이 어긋남.
   - 전경 ROI가 오른쪽 배경 반사광까지 포함해 박스 폭이 실제보다 넓게 잡힘.
3. **슬라이더 조작 시 심한 렉(Lag)**
   - `detectDenseVialCores`의 NMS 2중 루프(`34×34`)가 모바일 CPU에서 수백 ms 이상 점유하고, 짧은 디바운스로 인해 매 틱마다 5장 일괄 재분석이 동기 실행됨.

## 2. 개선 설계
1. **캡 뚜껑 외곽 윤곽선 정밀 검증 + 겹침 완벽 차단**:
   - 모든 후보 원에 대해 **반지름 `r` 경계선상의 원형 방사형 그라디언트 지지율(Radial Edge Support) 및 4분면 커버리지** 검증 필수화 -> 덧신/트레이 모서리 100% 제거.
   - 주변에 이웃 캡이 전혀 없는 고립된 1~2개 오탐(군집 외곽 노이즈) 제거 필터 추가.
   - 중복 제거 거리를 `dist < (c.r + k.r) * 0.88`로 강화하여 1캡 1마커 보장.
2. **적재 박스 옆모습 외곽 윤곽선 정밀 분할**:
   - 전경 추출 시 채도 + 밝기/엣지 결합으로 배경 반사광 제외, 실제 박스 폭(`leftX ~ rightX`) 정밀 크롭.
   - 층간 최소 간격을 고정값이 아닌 적재 높이/폭 비례 동적 간격(`Math.max(22, Math.round(roiH * 0.07))`)으로 계산해 가로/세로 사진 모두 정확히 분할.
3. **슬라이더 렉 완전 제거 (속도 20배 이상 향상)**:
   - `detectDenseVialCores` NMS를 8x8 타일 블록 최대값 추출 방식으로 최적화 (연산시간 < 35ms).
   - `pages/index.jsx` 슬라이더 디바운스를 `320ms`로 조정하고 `setState` 밖에서 비동기 실행.
