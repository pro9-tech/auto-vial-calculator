# 05. 자동바이알계산기 — "기록" 화면 수정 계획서

## 1. 목적
- 체이스의 7가지 수정 요청사항을 반영하여 "기록" 화면을 더 간결하고 직관적으로 정돈합니다.
- 복잡한 통계와 판정 상태를 덜어내고, 제품명과 실제 파악된 개수 중심의 깔끔한 한 줄 표 형태로 개편합니다.

## 2. 세부 수정 사항
1. **'판정상태' 삭제**:
   - 표 헤더 `<th>판정 상태</th>` 및 데이터 셀 `<td>` 삭제.
2. **'상세열람' 버튼 글씨 삭제**:
   - `열람` / `닫기` 텍스트를 제거하고, 아이콘 버튼(`.jt-icon-btn` 또는 아이콘 전용 버튼)으로 심플하게 변경 (`aria-label` 필수 준수).
3. **'파악갯수' 표기 간소화**:
   - 기준 수량(`spec`) 병기 표기를 제거하고, 실제 파악된 수량만 표기 (예: `100 개`).
4. **'로트번호' $\rightarrow$ '제품명' 변경 및 자유 기재 지원**:
   - 컬럼 제목을 `제품명`으로 변경.
   - 추후 및 현재 즉시 자유롭게 기재/수정할 수 있도록 `.jt-input.jt-input-sm` 인라인 입력 필드 제공 (placeholder 및 기본 제품명 샘플).
5. **검색창 빈칸 유지**:
   - 검색창 기본값을 빈칸으로 두고 직관적인 placeholder 제공.
6. **모든 글씨 한 줄 표시 및 글자 크기 조정**:
   - 글자 크기를 살짝 줄여(`var(--fs-sm)`) 좁은 화면에서도 텍스트가 줄바꿈되지 않도록 `whiteSpace: 'nowrap'` 처리.
7. **상단 요약 통계 카드 삭제 및 검색창 상단 배치**:
   - '최근 검수 총 바이알', '적합 판정률', '총 검수 LOT' 통계 영역 제거.
   - 검색창을 상단 제목 바로 아래로 끌어올려 접근성 강화.

## 3. 사용하는 `.jt-*` 컴포넌트 목록
- 레이아웃·카드: `.jt-card`, `.jt-row`, `.jt-stack-2`, `.jt-stack-3`, `.jt-stack-4`
- 버튼·스위처: `.jt-btn`, `.jt-icon-btn`, `.jt-switcher`, `.jt-switcher-item`
- 입력·검색: `.jt-input`, `.jt-input-sm`
- 표·분류: `.jt-table-wrap`, `.jt-table`, `.jt-num`, `.jt-tag`, `.jt-badge`
- 상태·설명: `.jt-empty`, `.jt-empty-title`, `.jt-empty-desc`, `.jt-skeleton`, `.jt-desc`
- 텍스트·아이콘: `.jt-help`, `.jt-ico`, `.jt-ico-sm`, `.jt-ico-lg`
