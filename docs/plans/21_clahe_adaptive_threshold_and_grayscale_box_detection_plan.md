# 21. 바이알 캡 CLAHE·적응형 이진화·침식 분리 및 박스 원본 흑백 가로선 검출 구현 계획서

## 1. 개요 및 목적
- **목적**: 
  1. 캡 모드: 밀집 바이알 촬영 시 캡들이 거대한 단일 덩어리로 뭉쳐 중앙부 바이알이 대량 누락(93개로 오인식)되는 문제를 해결하기 위해, CLAHE(적응형 히스토그램 평활화) + 적응형 이진화(adaptiveThreshold) + MORPH_CLOSE(검은 점 메우기) + cv.erode(침식 분리) + cv.distanceTransform 피크 추출 파이프라인을 구축하여 99% 정확도 달성.
  2. 박스 모드: 초록색 마스크로만 처리 시 층간 가로 그림자선이 소멸하여 5박스 등으로 뭉개지는 현상을 해결하기 위해, 원본 이미지의 흑백(Grayscale) 명암 프로파일(Sobel Y 및 행별 밝기 골짜기) 기반으로 실제 층수를 정확히 분할하고 상단 뚜껑 평면을 자동 제외.
  3. 디버그 전처리 보기 화면 개선: 체이스가 눈으로 "캡 하나하나가 서로 떨어져 있는 흰색 원반"과 "박스 가로 경계선"을 즉시 확인할 수 있도록 시각화 출력 개선.

## 2. 상세 구현 단계

### 단계 1: 바이알 캡 모드 알고리즘 전면 개편
1. **초록 배경 마스킹**: HSV 색상 공간(H 65~175, S >= 0.20)으로 트레이 배경을 검정(0)으로 완전히 소거.
2. **CLAHE 적용**: 캡 표면과 캡 사이의 미세한 그림자 틈새 대비를 극대화.
3. **적응형 이진화 (adaptiveThreshold)**: 조명 차이에 영향받지 않고 캡 표면은 흰색(255), 캡 사이 경계선은 검정(0)으로 분리.
4. **MORPH_CLOSE & erode 침식**:
   - 캡 중앙의 작은 검은 점을 메워 꽉 찬 원반으로 만듦.
   - cv.erode(침식)를 1~2회 적용해 미세하게 붙어 있는 캡 경계들을 완전히 떼어냄.
5. **Distance Transform & 피크 추출**:
   - 분리된 원반들에 distanceTransform을 적용.
   - 바이알 지름의 약 75%를 최소 거리(minDist)로 지정해 로컬 최댓값(피크)만 추출.
6. **디버그 뷰**: 침식 분리된 개별 원반(또는 피크) 이미지를 흑백으로 즉시 확인 가능하도록 전처리 뷰어 연결.

### 단계 2: 카트 박스 모드 알고리즘 전면 개편
1. **HSV 마스크의 역할 제한**: 박스 전체 덩어리의 바깥 영역(좌측 열, 우측 열 영역 및 전체 번들 외곽)을 찾는 ROI 용도로만 사용.
2. **원본 흑백(Grayscale) 가로선 검출**:
   - 원본 이미지의 흑백 밝기 데이터에서 세로 방향 밝기 변화(Sobel Y 및 행별 평균 밝기 프로파일)를 계산.
   - 박스와 박스 사이의 어두운 가로 그림자 골짜기(Valley) 위치를 정확히 검출.
3. **박스 윗면(뚜껑 평면) 자동 제외**:
   - 가로 그림자 선 간격이 비정상적으로 넓은 최상단 뚜껑 평면 영역을 감지하여 박스 앞면 검출 영역에서 제외.
4. **개별 사각형 박스 매핑**: 실제 앞면의 각 층 경계선마다 개별 사각형 테두리와 번호를 부여.
