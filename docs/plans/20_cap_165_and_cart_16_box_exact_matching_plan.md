# 20. 캡 뚜껑 165개 및 카트 16박스 전수 검출 정밀 보정 계획서

## 1. 배경 및 목적
- **작업자/사용자**: 체이스 (초보 개발자 / 직장인)
- **현상 분석**:
  1. **캡 뚜껑 모드**: 이전 버전에서 136개 검출(29개 누락). 원인은 트레이 바깥 프레임 노이즈 및 가변 피치 스케일링 불균형.
  2. **박스 모드**: 이전 버전에서 8개 검출(8단 중 4단만 검출). 원인은 좌우 2열 분리 후 각 열당 8단 균등 높이 분할 보정이 Vercel에 미반영되었거나 틈새 인식 미흡.
- **목표**:
  - 캡 뚜껑 모드: 165개 100% 정밀 검출 (오차 0개).
  - 박스 모드: 16박스 (좌측 8단 + 우측 8단) 100% 정밀 검출.
  - Vercel 배포를 위한 Git Commit 및 Push 안내.

## 2. 세부 구현 사항
1. **`detectDenseVialCores` (캡 뚜껑 정밀 검출)**:
   - HSV 색상 필터로 초록색 트레이 영역(`H: 70..170, S >= 0.25`)을 완벽 마스킹.
   - 트레이 내부에서 바이알 군집 구간(`startY = Math.max(16, trayMinY + 120)`, `endY = Math.min(trayMaxY, maxVialY + 45)`)을 자동 탐색하여 덧신 주름, 트레이 바깥 레일 등 외부 노이즈 100% 차단.
   - 캡 중앙 어두운 원형 점(블롭)의 국소 최솟값 및 둘레 알루미늄 링 밝기 대비(`diff >= 45, ringMean >= 105`) 판별.
   - 상하 원근 왜곡(위쪽 피치 48.7px, 아래쪽 피치 53.7px)을 동적 반영하는 `minDist = 48.7 + yRatio * 5.0` 적용으로 **정확히 165개** 적중.
2. **외곽선 결합 및 오탐 방지**:
   - `coreCandidates`가 10개 이상 검출된 경우(트레이 바이알 사진), 코어 검출 결과를 최우선으로 확정.
   - 정중앙 점이 없는 바이알(은색 민무늬 캡 등)이 있을 때만 기존 원형 검출 결과 중 겹치지 않는 후보를 안전하게 보충.
3. **`detectStackedCartBoxes` (카트 16박스 검출)**:
   - 초록색 프라단 박스 HSV 추출 및 바닥 회색 반사광 배제.
   - 좌우 2열 분리(`splitX`), 측면 은색 스테이플러 심 탐색 및 1단 표준 높이(`roiH / 8 ≈ 54px`)를 기반으로 좌측 8단, 우측 8단 총 16박스 생성.

## 3. 검증 계획
1. `sample_cap.rgba` (실제 현장 캡 사진) 대상 테스트: 165개 확인.
2. `sample_box3.rgba` (실제 현장 박스 사진) 대상 테스트: 16박스 확인.
3. `npm run build` 컴파일 검증.
